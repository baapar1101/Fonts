SmartOrganizedPlus

Hierarchy: script / style / weight / family / variable-or-static / format.
Categories are inferred from font metadata, cmap coverage, and names.
Built from every raw source folder (see RAW_SOURCES in organize_all_fonts.py),
de-duplicated by exact file content (sha256). Original folders are untouched.

To add new fonts: drop files into _Incoming, then re-run
    python organize_all_fonts.py
    python build_index.py
